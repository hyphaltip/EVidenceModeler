# Release 2.5.0 (Rust)
- bugfix: augustus_GTF_to_EVM_GFF3.pl, augustus_merge_stop_codons_to_GFF3.pl,
  and the Rust augustus_to_evm_gff3 port all corrupted Augustus gene models
  run with --stopCodonExcludedFromCDS=False (funannotate's BUSCO training
  default): the stop_codon feature already lies inside the emitted CDS span
  in that mode, but the converters unconditionally re-added it as a second,
  overlapping CDS/exon segment, producing a negative-length intron that made
  downstream Augustus etraining reject the model. A stop_codon segment is
  now only folded in when it does not already overlap an existing CDS
  segment for that model; when it's a true adjacent segment (the historic
  --stopCodonExcludedFromCDS=True case) it is still merged into one
  continuous CDS span, matching Gene_obj::join_adjacent_exons(). The Rust
  port additionally used to silently drop stop_codon segments outright
  (never merging the adjacent case), truncating the CDS by 3bp; it now
  mirrors the corrected Perl logic exactly. Verified against a real
  funannotate BUSCO training run where 177/178 training models were
  corrupted by this bug.
- Packaging, CI, and docs hardening for the Rust rewrite (funannotate
  integration guide, module-file install instructions).
- Resolved all clippy warnings for CI compliance.
- Ported augustus_to_evm_gff3 and gff3_gene_prediction_file_validator from
  EVidenceModeler_rust.
- 99.6% gene-level parity with the Perl implementation.

# Release 2.1.0 (Rust rewrite)
- Full Rust port of the EVM pipeline: evidence_modeler, partition_evm_inputs,
  recombine_evm_outputs, convert_EVM_outputs_to_GFF3, gff3_file_to_proteins,
  and the EVidenceModeler orchestrator.
- Drop-in replacement for Perl evidence_modeler.pl in funannotate.
- 99.4% gene-level parity and 97.0% protein sequence parity with the Perl
  implementation on a real fungal genome (Rhodotorula sphaerocarpa, 24
  scaffolds, ~20 Mb).
- Parallel execution via rayon (no external ParaFly dependency for the Rust
  path).
- CI: cargo fmt --check, cargo clippy -D warnings, cargo test, and golden
  integration tests on every PR.
